# 交通可达性分析系统

交通可达性分析系统是一款面向 GIS、旅游管理与交通地理研究的本地批量路线采集工具。它可以导入多组起点和目的地，按计划发起驾车路线查询，保存路线距离、预计耗时和实际采集时间，并导出供后续分析使用的数据。

> 它帮助研究者有组织地查询、保存和核对路线数据；它不是导航软件，也不会生成历史路况或未来预测路况。

## 适合谁、用于什么

- **旅游管理、旅游地理与交通地理方向的学生和研究者**：批量比较客源地到景点、乡村旅游重点村等目的地的道路可达性。
- **GIS 与空间分析人员**：从 CSV/Excel 导入坐标，检查坐标和字段，批量获得道路距离、预计行车时间并导出后续分析所需数据。
- **规划与区域研究人员**：在不同日期、时段或情景下采集路线结果，并检查哪些路线成功、失败或缺测。

适用于已具备地图服务权限、需要批量或多日采集路线数据的本地研究工作。这里的“起点到终点路线”有时简称 OD。软件用于整理和采集研究数据，不替代导航软件，也不提供交通预测或历史交通回放。

## 主要功能

- **批量地点导入**：读取 CSV 和 Excel，自动识别常见中英文表头（包括中文表头），检查经纬度、坐标系、重复编号及无效记录。
- **坐标记录与转换**：支持 WGS84、GCJ-02、BD-09 坐标标识和转换；导入时保留原始数据，研究文件已经使用 GCJ-02 时可直接用于高德路线查询。
- **多起点、多目的地路线查询**：规划去程、返程或双向路线；支持完整 OD 对比及附近目标的缩小规模模式。
- **立即或定时采集**：按计划日期和时刻启动一轮查询，保存每条路线自己的实际请求与响应时间；支持多日计划、顺序控制、限流、暂停与恢复。
- **高德路线服务与模拟模式**：配置高德 Web 服务 Key 后请求驾车路线；模拟模式用于检查操作流程，不产生真实交通观测，不能用于研究结果。
- **质量核查与导出**：查看成功、失败、待采、错过时间及采集完整性；导出路线明细、汇总、研究数据包、请求记录和数据字段说明。
- **本机数据管理**：应用只监听本机地址，数据保存在本机数据库与文件目录；API Key 不会显示在导出结果中。

## 重要的数据解释

高德普通驾车路线接口返回的是**请求时的路线与预计耗时估算**。计划里的日期和时间用于安排查询并标记研究情景，并不意味着接口会返回该时刻的历史或预测路况。每条路线按自己的实际请求时间记录，不能把整轮数据理解为所有路线在同一秒采得。

路线失败、没有返回路线或未能在窗口内查询到，表示缺测或查询失败，**不能据此认定地点不可达**。路况只按接口实际返回内容保存；未返回的信息保持缺失。

## 本机运行

需要 Python 3.11 或更新版本。克隆源码后，在项目目录运行：

```bash
python3 -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
python start.py
```

应用启动后会在默认浏览器打开本机页面。Windows 激活虚拟环境后运行 `python start.py`。配置高德 Key 后才会发起高德请求；选择模拟模式不会调用真实路线服务。

macOS 应用打包：

```bash
python scripts/build.py
```

自动化测试：

```bash
python -m pip install pytest
python -m pytest -q
node --check frontend/app.js
node tests/test_frontend_research.cjs
```

## 使用流程

```text
准备客源地和目的地坐标文件
→ 在“研究地点/数据管理”导入并检查
→ 配置高德 Key，或先用模拟模式熟悉流程
→ 选择路线方向和采集日期、时刻
→ 检查预计请求量、窗口和账户额度
→ 小规模试采
→ 正式采集
→ 查看质量报告并导出数据
```

开始大批量采集前，请先用少量点位试运行，确认坐标、路线策略、服务额度、请求速度和采集窗口符合研究需要。运行定时采集时，电脑必须保持开机、联网、不休眠，应用不能退出。

## 当前范围与限制

- 使用高德路线服务前，需要在高德控制台确认 Key、服务权限、调用频率和剩余额度；软件中的本机限流设置不等于高德账户授权。
- 真实查询结果取决于网络、账户状态及接口在请求时的返回。模拟数据只用于检查操作流程，不能作为真实交通观测；离线性能测试也不代表高德服务的实际速度。
- 软件记录的是路线服务在实际请求时返回的规划结果，不提供车辆 GPS 实测轨迹、静态路网模型、历史路况、指定时刻的预测路况或实时地图，也不会自动得出因果结论。
